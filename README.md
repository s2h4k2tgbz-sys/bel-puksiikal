# Bel Puksiikal · GitHub Pages

Sitio estático listo para publicar en GitHub Pages.

## Publicar

1. Sube **el contenido de esta carpeta** a la raíz de tu repositorio `bel-puksiikal`.
2. En GitHub, abre **Settings → Pages**.
3. Elige **Deploy from a branch**, rama **main**, carpeta **/(root)**.
4. Guarda y espera a que GitHub publique la página.

## Antes de publicar

- Abre `script.js` y escribe el número real de WhatsApp en `whatsappNumber` (solo dígitos, incluyendo el código de país).
- Para añadir la foto real de Kusuma, sustituye el bloque `.portrait` en `index.html` por una imagen propia, o cambia su imagen de fondo en `style.css`.
- Se pueden cambiar los enlaces de navegación, textos y fotografías sin instalar nada: el sitio funciona como archivos estáticos.

## Archivos

- `index.html`: contenido y estructura.
- `style.css`: diseño adaptable a móviles.
- `script.js`: menú móvil, año automático y formulario de WhatsApp.
